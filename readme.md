# Обход препятствий мобильным роботом
## Задание
Необходимо обеспечить управление мобильным роботом: над полем, по которому движется робот, установлена камера, транслирующая видео. Пользователем в реальном времени на видеопотоке задается конечная точка, в которую должен приехать робот; определяя препятствия и объезжая их, робот должен прибыть в конечную точку. Необходимо отобразить координаты робота во время перемещения, а также длину пройденного им пути.

## Обработка видеопотока
Первым этапом будет работа с видеопотоком. Необходимо:

- Провести предобработку видеопотока, выровнять изображение с камеры
- Иденцифицировать положение робота
- Определить препятствия на поле
- Реализовать возможность задания координат конечной точки по видеопотоку

Так как камера установлена не ровно, необходимо выровнять кадры таким образом, чтобы соблюсти реальные пропорции. Так как поле и камера статичны, а размеры поля известны - углы поля просто указываются вручную и записываются в отдельном файле для дальнейшего выравнивания кадров видеопотока.

## Алгоритм и условия движения
Так как большинство методов построения маршрута являются графовыми (или дискретными), то есть строятся по точкам - то обрабатываемый кадр разбивается на точки, по которым будет строиться путь.

В качестве реализуемого алгоритма построения маршрута выбран жадный алгоритм. Так как подразумевается, что пользователь ставит цель для робота вручную - было принято, что необходимо как можно быстрее простраивать маршрут.

Жадный алгоритм представляет собой принятие на каждом этапе построения маршрута локально оптимального решения.

Для избежания столкновений с препятствиями на препятствия, поверх их контура, накладывается маска с радиусом робота, что позволяет точно определить, сможет ли робот проехать мимо них. Также для избежания столкновения с краями поля сделан отступ в радиус робота (он задается отдельно, чтобы иметь возможность сделать отступ больше, но примерно равен радиусу робота).

Так как роботу необходимо строить маршрут по точкам - то и маска препятствия строится по точкам, окружающим его, таким образом маршрут может строиться вдоль препятствия.



## Взаимодействие с роботом

На основе пути, построенного алгоритмом, формируются скорости, необходимые для достижения цели. Для управления роботом используется П-регулятор: чем больше расстояние до цели, тем больше скорость. Скорость движения робота также ограничена сверху.

Скорости вдоль осей X и Y передаются роботу по Wi-Fi.
